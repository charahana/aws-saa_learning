## VPCの概要
### VPCとは
- VPC（Virtual Private Cloud）はAWS上に構築する論理的に分離された仮想ネットワーク
- IPアドレス範囲を指定してAWSリソースを配置するネットワーク環境を構築できる
- リージョン内に作成し、複数のAZにまたがって利用できる
### VPCの基本構成
| 構成要素 | 役割 |
| ------ | ------ |
| VPC | AWS上の仮想ネットワーク |
| CIDR | VPCやサブネットで使用するIPアドレス範囲 |
| サブネット | VPC内のネットワークを分割する |
| ルートテーブル | 通信の経路を制御する |
| Internet Gateway | インターネットとの通信を可能にする |
| NAT Gateway | プライベートサブネットから外部への通信を可能にする |

## CIDR/IPアドレス設計
### CIDRとは
- IPアドレスの範囲を表現するための表記方法
- 例：10.0.0.0/16
- `/16`などの数字はネットワーク部の長さを表す
### CIDRの比較
| CIDR | IPアドレス数 |
| ------ | ------ |
| /16 | 65,536 |
| /24 | 256 |
| /25 | 128 |
| /26 | 64 |

## サブネット
### サブネットとは
- VPC内のIPアドレス範囲を分割したネットワーク
- 1つのサブネットは1つのAZに属する
### パブリックサブネットとプライベートサブネット
| 比較項目 | パブリックサブネット | プライベートサブネット |
| ------ | ------ | ------ |
| インターネットへの直接経路 | IGWへのルートあり | IGWへの直接ルートなし |
| 主な用途 | Webサーバー、ALBなど | DBサーバー、内部アプリケーション |
| 外部通信 | IGW経由 | 必要に応じてNAT Gateway経由 |

## ルートテーブル
### ルートテーブルとは
- ネットワーク通信の宛先と転送先を定義する
- 各サブネットは1つのルートテーブルに関連付けられる
### 代表的なルート
| 宛先 | ターゲット | 用途 |
| ------ | ------ | ------ |
| VPCのCIDR | local | VPC内の通信 |
| 0.0.0.0/0 | IGW | IPv4インターネット通信 |
| 0.0.0.0/0 | NAT Gateway | 外部へのIPv4通信 |

## Internet Gateway / NAT Gateway
### 役割の違い
| 比較項目 | Internet Gateway | NAT Gateway |
| ------ | ------ | ------ |
| 主な役割 | インターネットとの接続 | プライベート側からの外部接続 |
| 主な用途 | パブリックサブネット | プライベートサブネット |
| 外部からの直接通信 | 条件を満たせば可能 | 外部からの新規接続は不可 |
| 配置 | VPCにアタッチ | サブネットに配置 |
### まとめ
- IGWはVPCとインターネットを接続する
- NAT Gatewayはプライベートサブネットからインターネットへの通信に利用する
- NAT Gatewayを利用する場合、通常はパブリックサブネットに配置する

## セキュリティグループ / ネットワークACL
### 役割の違い
| 比較項目 | セキュリティグループ | ネットワークACL |
| ------ | ------ | ------ |
| 制御対象 | ENIなどのリソース | サブネット |
| ステート | ステートフル | ステートレス |
| ルール | 許可ルールのみ | 許可・拒否ルール |
| ルール評価 | すべてのルールを評価 | 番号の小さい順に評価 |
### まとめ
- セキュリティグループはリソース単位で通信を制御する
- ネットワークACLはサブネット単位で通信を制御する
- ステートフルとステートレスの違いを理解する

## VPC Endpoint
### VPC Endpointとは
- VPCからAWSサービスへプライベート接続するための仕組み
- インターネットやNAT Gatewayを経由せずにAWSサービスへアクセスできる
### 種類
| 種類 | 特徴 | 代表例 |
| ------ | ------ | ------ |
| Gateway Endpoint | ルートテーブルを利用 | S3 / DynamoDB |
| Interface Endpoint | ENIを利用したプライベート接続 | SQS / SNS / Systems Managerなど |

## VPC間接続・オンプレミス接続

### 接続サービスの比較
| サービス | 主な役割 | 用途 |
| ------ | ------ | ------ |
| VPC Peering | 2つのVPCを接続 | VPC間通信 |
| Transit Gateway | 複数のネットワークを集約接続 | 多数のVPC・オンプレミス接続 |
| Site-to-Site VPN | VPNによる接続 | オンプレミスとの暗号化通信 |
| Direct Connect | 専用ネットワーク接続 | 安定した専用接続 |

## 今回の学習で重要だと感じたこと
- VPCはAWS上の仮想ネットワークであり、各機能が連携して通信を実現している

| ------ | ------ |
| CIDR | IPアドレスの範囲をどう設計するか |
| サブネット | リソースをどのネットワークに配置するか |
| ルートテーブル | 通信をどこに転送するか |
| Gateway | どのネットワークと接続するか |
| セキュリティ | どの通信を許可・拒否するか |
| VPC Endpoint | AWSサービスへどう接続するか |
| VPC間接続 | 他のVPCやオンプレミスとどう接続するか |

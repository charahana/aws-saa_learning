## 概要
このリポジトリはaws-saa資格取得を目標とした学習記録です。
ping-tを使って知識習得に向けて、クラウド基礎から実践までを学習しております。

## 使用ツール
- ping-t (学習ツール)
- アマゾンウェブサービス (運用の確認)
- Visual Studio Code (学習ログ作成)
- GitHub (記録・Git管理)

## 今後の学習方針
- 学習内容を毎日、学習ログとして記録を残す
- 理解した内容を自分の言葉で整理する
- Ping-tを活用して知識の定着と苦手分野の克服を行う
- 会社で学んだ内容を活かし学習を深堀りする

## 意識すべきポイント
「知識を身に付ける」だけでなく、
「なぜそうなるのかを理解して、実際に手を動かして確認する」を意識する。
